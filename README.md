# Squark

Squark is a simulation of a dungeon infested with monsters. Dare you create a character and try to survive? You might just encounter others exploring or the monsters who call this place their home, who may not be happy to see you...

Squark is a multiplayer dungeoun-crawling simulation. It isn't really a *game*, since there isn't a goal (yet), but it is certainly a simulation. A version of the main branch is running on [squark.ca](https://squark.ca) if you want to check it out!
